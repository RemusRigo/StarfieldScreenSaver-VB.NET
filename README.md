# Starfield ScreenSaver
Starfield ScreenSaver



## 👤 Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## ✨ Features

* Multi-monitor support (one form per screen)
* Preview in the Windows Screen Saver Settings dialog
* Per-monitor DPI awareness: sharp on scaled displays
* Settings: number of stars, speed and trails, saved in the Registry
